## gulp-2022

**Tutorial video:** [YouTube](https://www.youtube.com/watch?v=jU88mLuLWlk)

> [!NOTE]
>
> **[HTML] Error: Callback called multiple times**: Ensure the `<img>` tag is written on a single line, and the image path contains no Cyrillic characters or spaces.
> **Updated `del` plugin syntax**: Use `import deleteAsync from "del"` for the current version.
> **Linux environment**: Use `gulp-fonter-unx` instead of `gulp-fonter` (which is designed for Windows).
